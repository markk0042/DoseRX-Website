Security & access control

Built to align with HSE information security expectations

DoseRX is engineered around confidentiality, integrity and availability — the controls HSE IT Security and Data Protection policies require for systems that process health-service information.

Authenticated user logins

Every practitioner and manager signs in with an individual account. No shared credentials. Access is role-scoped (clinical staff vs management) so people only see what their duty requires — matching HSE access-control and least-privilege expectations.

Hashed credentials

Login secrets (PINs / passwords) are stored using strong, salted cryptographic hashing — never as plain text. Verification compares hashes only, in line with HSE password-security practice and GDPR integrity requirements.

Row Level Security (RLS)

Database Row Level Security policies enforce organisation and role boundaries at query time. Even if a request is malformed, the data layer refuses rows the user is not authorised to read or change.

Encryption in transit & at rest

Traffic is protected with modern TLS. Stored data is encrypted at rest — supporting HSE Encryption Policy expectations for systems that hold operational and accountability records.

Dual-control on controlled drugs

High-risk CD actions require a second authenticated witness PIN. That separation of duties strengthens accountability and reduces single-user diversion risk.

Full activity audit trail

Sign-ins, bag movements, administrations, waste, and discrepancy actions are logged with actor, witness, time, and optional GPS / photo evidence — supporting monitoring, investigation, and inspection readiness.

Policy alignment

DoseRX security design maps to the themes in HSE’s IT Security Policy (access control, password standards, encryption, monitoring), the Personal Data Protection Policy (data minimisation, privacy by design, integrity & confidentiality), and the direction set in the Cyber Security Statement of Strategic Intent 2024–2027 — including GDPR-aligned processing and identity / access safeguards.
